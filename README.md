# Python File Organizer

A Python-based utility that automatically organizes files into folders based on their file extensions.

## Features

- Automatic file categorization
- Duplicate filename handling
- Dry-run mode
- Error handling
- Activity logging
- Organization summary

## Technologies

- Python
- pathlib
- shutil
- logging

## Python Concepts Practiced

- Variables
- Dictionaries
- Conditional statements
- For loops
- While loops
- Functions
- Function arguments
- Return values
- Exception handling
- File handling
- Boolean values
- f-strings
- Logging
- Docstrings

## How It Works

The program:

1. Takes a folder path from the user.
2. Scans the files inside the folder.
3. Identifies each file's extension.
4. Determines the appropriate category.
5. Creates the required folder.
6. Handles duplicate filenames.
7. Moves the files.
8. Displays a summary.

## How to Run

```bash
python organizer.py
